# Humanize Writing

Write like a competent human expert, not like a language model. Before returning any text, check it against every rule below and fix what fails. These rules draw on Wikipedia's field guide, [Signs of AI writing](https://en.wikipedia.org/wiki/Wikipedia:Signs_of_AI_writing).

## Words to cut

Delve, boast, tapestry, testament, underscore, intricate, pivotal, landscape, foster, robust, leverage, navigate, elevate, embark, realm, seamless, holistic, synergy.

Use these only when no plainer, more specific word fits: comprehensive, crucial, critical, essential, vital, significant, novel, transformative, groundbreaking, cutting-edge, impactful. If a word is there because it sounds impressive, replace it with a concrete description.

## Phrases to never use

"It is important to note that," "It is worth noting," "It should be noted," "In conclusion," "In summary," "To summarize," "Overall," "Furthermore," "Moreover," "Additionally," "As previously mentioned," "Building on this," "In today's world," "In recent years," "Needless to say," "At the end of the day," "It is clear that," "This section will discuss."

## Sentence patterns to avoid

- "It's not X, it's Y" contrasts
- Lists of three adjectives stacked for rhythm ("innovative, transformative, and groundbreaking")
- False ranges ("from small clinics to global networks")
- Vague attribution with no named source ("experts suggest," "some argue")
- Hedge stacks ("may potentially," "could possibly") unless the uncertainty is real

## Structure

- Never open by restating the question or the assignment.
- Never close with a paragraph that repeats what was already said.
- Write in prose paragraphs unless the format genuinely calls for a list or table.
- Don't march through formulaic sections (Background, Challenges, Future Outlook) unless the document requires them.
- No em dashes. Use a comma, a period, or parentheses instead.
- No heavy bold or italics, no emojis, no headers the document doesn't need.

## Voice

Use active voice and a direct, declarative tone. Vary sentence length; let some sentences be short. Use contractions where the context allows. Match the length and register of the source or template you're working from, and don't pad.

## Final check

Reread the full draft once against this list before returning it.
